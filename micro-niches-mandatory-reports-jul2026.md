# 12 professional micro-niches: mandatory / quasi-mandatory reports ($300–$5,000) — July 2026

Scope: solo / small certified practitioners; deliverable assembled from photos + field forms + Excel/Word/PDF; excludes previously checked niches (home inspection, radon, wetland, ecology/bat, knotweed, historic structures, acoustics, lead, mold, asbestos, fire doors, chimney, backflow, septic, marine/aviation, appraisals, expert witnesses, NDT, CMT, playgrounds).

**Generic field-report platforms (apply across niches unless noted):** SafetyCulture/iAuditor, Fulcrum, GoCanvas, TrueContext, GoAudits, GoFormz, Forms On Fire, Lumiform, FormRift, Spectora/HIP/TapInspect (home-inspection oriented), ReportWalk (voice-to-report). Sources: [formrift.com/blog/safetyculture-iauditor-alternatives](https://www.formrift.com/blog/safetyculture-iauditor-alternatives), [goaudits.com/blog/fulcrum-alternatives](https://goaudits.com/blog/fulcrum-alternatives/), [blog.reportwalk.com](https://blog.reportwalk.com/digital-inspection-software-guide/).

## 1. California CASp Access Compliance Report (CRASCA)

| Field | Fact |
| --- | --- |
| **Law / standard / trigger** | Cal. Civ. Code §§55.51–55.545 (CRASCA); CASp certification via DSA (Gov. Code §4459.5 et seq.). Trigger: Qualified Defendant status / reduced Unruh damages / litigation stay when report obtained pre-suit; also remodel/lease/sale diligence. ADA Standards + CBC Ch. 11B. Official: [dgs.ca.gov CASp Property Inspection](https://www.dgs.ca.gov/DSA/Resources/CASp-Property-Inspection); report content cheat sheet: [CASI-CASpReportCheatSheet.pdf](https://www.dgs.ca.gov/-/media/Divisions/DSA/Publications/casp/CASI-CASpReportCheatSheet.pdf). |
| **Practitioners** | DSA list scrape Jul 2026: ~938 certification numbers on public list; ~401 marked “Do Inspections = Yes” ([DSA CASp list](https://www.apps2.dgs.ca.gov/DSA/CASP/casp_certified_list.aspx)). Industry cites ~800–1,000 CASps / ~4.1M CA businesses ([caspcalifornia.com](https://www.caspcalifornia.com/resources/casp-inspection-cost); [caspinspectors.com](https://caspinspectors.com/blogs/ada-non-compliance-cost-vs-casp-inspection-roi/)). Corey & Partners: of ~800, only ~100 actively inspect private commercial ([coreyandpartners.com](https://www.coreyandpartners.com/post/hiring-a-licensed-casp-not-all-accessibility-professionals-are-created-equal)). Exam pass rate cited ~39%. |
| **Avg report price** | Small–medium commercial: **$650–$3,500** typical; campus/shopping center $10k–$50k+ ([caspinspectors.com](https://caspinspectors.com/blogs/ada-non-compliance-cost-vs-casp-inspection-roi/), [caspcalifornia.com](https://www.caspcalifornia.com/resources/casp-inspection-cost)). |
| **Frequency** | Not fixed by statute; industry 3–5 years or after remodel/complaint ([caspinspectors.com](https://caspinspectors.com/blogs/why-casp-inspections-matter/)). |
| **Manual workflow evidence** | DSA: no official Word template; CASp must produce CRASCA-compliant written report with measurements, photo essay recommended ([CASp Best Practices Manual](https://www.dgs.ca.gov/-/media/Divisions/DSA/Publications/casp/CASp1_Manual2024.pdf)). DAIC certificate ordered via DSA forms. |
| **Competitor sweep** | **Niche:** few dedicated CASp report SaaS products publicly marketed; practice is custom Word/PDF. **Generic:** SafetyCulture, Fulcrum, GoCanvas, Spectora (poor fit for measurement-heavy 11B). No dominant vertical CASp platform found in Jul 2026 search. |
| **Achievable SOM (transparent)** | Federal ADA Title III CA filings 2024: 3,252 ([adatitleiii.com](https://www.adatitleiii.com/2025/03/ada-title-iii-federal-lawsuit-numbers-rebound-to-8800-in-2024/)); CCDA 2024: 4,319 complaints/prelitigation letters ([CCDA 2024 Annual Report](https://www.dgs.ca.gov/-/media/Divisions/CCDA/Tabs/Resources-Page/Annual-Reports/CCDA-2024-ANNUAL-REPORT.pdf)). If 5,000–15,000 proactive small-site CASp reports/yr × $1,500 mid = **$7.5M–$22.5M TAM slice**; 5–10% software attach @ $50–150/report or $50–100/mo/seat → **SOM ~$0.4M–$2.3M ARR** for a niche tool capturing active private inspectors (~100–400). |
| **Channel** | DSA public CASp list; CRE brokers; insurance/risk; plaintiff-defense bar referrals; Google “CASp [city]”. |
| **Liability** | Report creates Qualified Defendant pathway; CASp professional liability for incorrect determinations; DAIC tracking. |
| **Verdict** | **Strong fit.** Clear statute, $750–$3.5k band, photo+measurement+Word assembly, thin vertical software, litigation-driven demand Jul 2026. |

## 2. ISA TRAQ Tree Risk Assessment written report (US / municipal permit markets)

| Field | Fact |
| --- | --- |
| **Law / standard / trigger** | ISA Best Management Practices – Tree Risk Assessment; TRAQ credential (TRAQ 3.0 effective Nov 5, 2025; 7-year term). Quasi-mandatory: municipal tree removal permits, HOA/insurance liability, shoreline/critical-area review (e.g. Seattle SDCI). Form: [ISA Basic Tree Risk Assessment Form](https://www.isa-arbor.com/Portals/0/Assets/PDF/Certification/Tree_Risk_Assessment_Form_V3.pdf) — ISA states form is for data collection **“not intended to be used as a report.”** |
| **Practitioners** | ISA: **>3,000 TRAQ holders** (JTA survey acknowledgment, Sep 2025) ([OCISA notice](https://associationdirectory.com) via associationdatabase.com release). Directory: [treesaregood.org](https://www.treesaregood.org/Find-an-Arborist). |
| **Avg report price** | TRAQ with documentation **$300–$800**; full permit arborist report **$500–$1,500**; multi-tree inventories **$550–$3,500** ([soundtreecarellc.com](https://www.soundtreecarellc.com/tree-risk-assessments), [tallahasseetreeservice.co](https://tallahasseetreeservice.co/tree-risk-assessment-tallahassee/), [foxvalleyarborist.com](https://foxvalleyarborist.com/services/tree-risk-assessment/)). |
| **Frequency** | Event-driven (permit, storm, sale, claim) + periodic municipal/HOA contracts; TRAQ study median risk assessments/year among TRAQ respondents = 25 ([JAUF 2023](https://doi.org/10.48044/jauf.2023.019)). |
| **Manual workflow evidence** | ISA fillable PDF field form → separate narrative client report (photos, matrices, recommendations). Explicit split between form and report ([ISA form instructions PDF](https://www.isa-arbor.com/Portals/0/Assets/PDF/Certification-Applications/ISA-Basic-Tree-Risk-Assessment-Form-Instructions.pdf)). |
| **Competitor sweep** | **Niche:** TreePlotter / inventory GIS tools; no dominant TRAQ-to-client-report SaaS found. **Generic:** Fulcrum (GIS), SafetyCulture, ArcGIS Survey123. Large firms (Davey, Bartlett, SavATree) use internal systems ([reqodata firm list](https://reqodata.com/en/certified-arborist-tree-risk-assessment-firms)). |
| **Achievable SOM** | Conservatively 10–20% of 3,000 TRAQ holders sell paid reports (300–600) × 25 reports/yr × $600 = **$4.5M–$9M service TAM**; software 8–12% attach → **~$0.4M–$1.1M ARR**. |
| **Channel** | ISA directory; municipal arborists; realtor/HOA; insurance adjusters; Google “TRAQ arborist [city]”. |
| **Liability** | High civil exposure if failure after “low risk” rating; TRAQ methodology used as defense/offense in claims. |
| **Verdict** | **Strong fit.** Credentialed solo consultants, mid-price reports, explicit form→Word/PDF workflow, weak vertical SaaS. |

## 3. California SB 721 Exterior Elevated Elements (balcony/deck/stair) inspection report

| Field | Fact |
| --- | --- |
| **Law / standard / trigger** | Cal. Health & Safety Code §17973 (SB 721): multifamily ≥3 units, wood-supported EEEs >6 ft above grade; inspect by deadline then **every 6 years**; retain reports. Qualifiers: architect, civil/structural engineer, certified building inspector/official, or A/B/C-5 contractor with 5+ years. WJE advisory: [wje.com PDF](https://www.wje.com/assets/media/files/wje-advisory-california-senate-bill-721.pdf). (SB 326 = condo HOA, architect/engineer only, 9-year cycle.) |
| **Practitioners** | Open to multiple license classes statewide; no single statewide inspector registry found. Market served by GCs, building inspectors, engineering firms (e.g. DrBalcony). |
| **Avg report price** | **$300–$500 per balcony/EEE** visual; large projects $75–$150/unit; invasive thousands/element ([aggcg.com](https://aggcg.com/sb-721-financial-guide-budgeting-costs-california/), [pestpatrol.com](https://pestpatrol.com/california-balcony-inspection-law-sb-721/), [greatbuildz.com](https://www.greatbuildz.com/blog/sb-721-balcony-inspection-law/)). Whole-building packages often $5k–$20k+. |
| **Frequency** | Every **6 years** after initial. |
| **Manual workflow evidence** | Photo documentation of EEEs + condition ratings + repair priorities in written report retained by owner. |
| **Competitor sweep** | **Niche (active):** ScribeWare EEE ([scribeware.com/eee-balcony-inspection-report-software](https://scribeware.com/eee-balcony-inspection-report-software/)); E3 Inspection Reporting Solutions ([e3-inspection-reporting-solutions.com](https://e3-inspection-reporting-solutions.com/)); DrBalcony App ([drbalcony.com/drbalcony-app](https://drbalcony.com/drbalcony-app/)). **Generic:** Spectora-class + SafetyCulture. |
| **Achievable SOM** | Millions of CA multifamily units; recurring 6-year cycle. If 50k–150k EEE elements inspected/yr × $400 = **$20M–$60M service**; software already contested — SOM for new entrant **~$0.5M–$2M ARR** if differentiating vs ScribeWare/E3/DrBalcony. |
| **Channel** | Apartment owners/managers, insurance, local building depts, CSLB license networks. |
| **Liability** | Structural safety of elevated wood elements; owner must repair unsafe findings; inspector E&O for missed decay/rot. |
| **Verdict** | **Valid niche but software contested.** Price/workflow fit; vertical apps already shipping. |

## 4. California HERS / ECC Field Verification report (CF-3R) — Title 24 Part 6

| **Practitioners** | CHEERS-certified ECC/HERS raters (list confidential per CEC) ([CEC confidentiality letter TN264127](https://efiling.energy.ca.gov/GetDocument.aspx?DocumentContentId=100822&tn=264127)); CHEERS approved ECC-Provider Nov 12, 2025 ([energy.ca.gov ECC-Providers](https://www.energy.ca.gov/programs-and-topics/programs/energy-code-compliance-program/ecc-providers-energy-code-compliance)). |
| **Avg report price** | Field testing **$295–$595 per system** incl. registry/CF3R ([calhers.net](https://calhers.net/services/ecc-testing)). Separate Title 24 CF-1R design reports $150–$500 residential ([brenergysolutions.com Title 24 cost](https://brenergysolutions.com/blog/how-much-does-title-24-report-cost)). |
| **Frequency** | Per permitted HVAC install / new construction event (high volume, not multi-year cycle). |
| **Manual workflow evidence** | On-site duct leakage, airflow, refrigerant, blower door → CF-2R/CF-3R forms registered in provider registry (CHEERS). Field data + photos historically mixed with paper/tablet then upload. |
| **Competitor sweep** | **Mandatory registry:** CHEERS data registry ([cheers.org](https://www.cheers.org/)). Provider Golden State Registry applying. **Generic field apps** secondary. Vertical reporting largely owned by CEC-approved registries. |
| **Achievable SOM** | Large permit volume but **registry lock-in**; software SOM for third party limited unless integrating as EDDS/field helper. Achievable third-party ARR likely **<$0.5M** without provider partnership. |
| **Channel** | HVAC contractors, builders, building departments, CHEERS Find-a-Pro. |
| **Liability** | False verification → code noncompliance, rater discipline via provider QA; CEC oversight. |
| **Verdict** | **Price/frequency fit; platform risk high.** State registry already is the report system of record. |

Expert Safety Services cites fines from ~$15k for noncompliance messaging ([expertsafetyservices.com](https://expertsafetyservices.com/anchor-verification/)). |
| **Frequency** | **Annual** inspection; **10-year** (or 5-year adhesive) certification. |
| **Manual workflow evidence** | Photo log of each anchor ID, deficiency list, written owner letter to window-cleaning employer; Pro-Bel electronic reporting + Customer Portal ([pro-bel.com inspection](https://pro-bel.com/services/fall-protection-inspection/)). |
| **Competitor sweep** | **Niche:** Pro-Bel portal (OEM-tied); manufacturer inspection programs. **Generic:** SafetyCulture asset inspection; InspectNTrack-class CMMS. Independent PE reports still Word/PDF. |
| **Achievable SOM** | Urban high-rise + mid-rise RDS stock; annual recurring. Software SOM for independent inspectors **~$0.3M–$1.5M ARR** outside OEM portals. |
| **Channel** | Window cleaning contractors, building engineers, BOMA, Pro-Bel/competitor dealer networks. |
| **Liability** | Fall fatality; building owner + inspector; OSHA citations. |
| **Verdict** | **Strong regulatory trigger; OEM portals capture much volume.** Solo PE/qualified inspectors still assemble photo+letter packages. |
